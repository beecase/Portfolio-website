# Personal Portfolio Website

A personal portfolio website built with HTML, CSS, JavaScript, PHP, and MySQL. It features interactive project showcases, blog updates, a photo gallery, and a functional contact form.

## 🚀 Features

* **Home & About:** Personal introduction and background.
* **Skills & Projects:** Showcase of technical skills and completed projects.
* **Photo Gallery:** Visual media display.
* **Dynamic Blogs:** Dynamic blog system powered by PHP and MySQL (`blogs.php`).
* **Contact Form:** Interactive contact form for direct messages (`contact.php`).

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Backend:** PHP
* **Database:** MySQL
